# 生产级提示词模板

> 覆盖 OpenAI 六大策略 + Anthropic 核心原则，适用于任意复杂任务。
> 使用方法：将 `{{占位符}}` 替换为实际内容，删除不适用的区块。

---

## 模板正文

```
<role>
你是一位 {{领域/职业身份}}，具备以下专业能力：
- {{能力1}}
- {{能力2}}
- {{能力3}}
你的回答需体现该角色的专业判断力与严谨性。
</role>

<task>
{{用一两句话精确描述你要模型完成的任务}}
任务目标：{{明确成功标准——模型做到什么算完成}}
任务约束：{{长度限制、语言、语气、禁止事项等}}
</task>

<context>
以下是与本任务直接相关的参考信息，请基于这些信息作答，不得凭记忆编造未在此处出现的事实：

<reference>
{{粘贴参考资料、文档片段、数据、API 返回值等}}
</reference>

<conversation_history>
{{如有多轮对话历史，精简后粘贴于此，仅保留与本任务相关的部分}}
</conversation_history>
</context>

<instructions>
请按以下步骤完成任务，并在最终回答前进行内部推理：

1. 理解任务：重述任务目标，确认你被要求做什么。
2. 信息检索：从 <reference> 中定位与任务相关的关键信息。如参考资料不足以下结论，明确指出缺失了什么。
3. 分析推理：基于检索到的信息进行推理，必要时分步推导。
4. 验证自检：检查推理是否自洽、结论是否有参考资料支撑、是否与已知事实矛盾。
5. 组织输出：按 <output_format> 指定的结构产出最终回答。

推理规则：
- 每条事实性论断须能在 <reference> 中找到依据；找不到依据时，标注"参考信息不足"。
- 若参考信息与本任务无关，忽略之，不要被无关内容带偏。
- 若各参考信息相互矛盾，指出矛盾点，不强行统一。
</instructions>

<examples>
以下示例展示期望的输出风格与结构：

<example_1>
输入：{{示例输入}}
输出：
{{示例输出——展示结构、语气、推理深度}}
</example_1>

<example_2>
输入：{{示例输入}}
输出：
{{示例输出}}
</example_2>
</examples>

<output_format>
请严格按以下结构输出（不要输出推理过程本身，只输出结论）：

{{结构说明，例如：}}
## 结论
{{一句话核心结论}}

## 依据
- {{依据1：引用参考信息来源}}
- {{依据2}}

## 详细分析
{{分点展开}}

## 不确定项
{{列出无法确认的内容，标注"参考信息不足"，不得编造}}
</output_format>

<safety>
- 不确定时说"我不确定"或"参考信息不足"，不得编造事实。
- 不在回答中臆测未给出的数据、人名、引用来源。
- 若任务超出你的能力或参考信息严重不足，直接声明无法完成，并说明缺什么。
</safety>
```

## 设计说明：每条原则落在哪里

| 原则 | 对应区块 | 体现方式 |
|------|---------|---------|
| ① 清晰优先 | `<task>` `<instructions>` | 目标、约束、步骤显式写出 |
| ② 给角色 | `<role>` | 定义身份+能力清单 |
| ③ 给示例 | `<examples>` | XML 标签包裹的少样本 |
| ④ 结构化分隔 | 全文 XML 标签 | role/task/context/examples 四区清晰隔离 |
| ⑤ 先思考后答 | `<instructions>` 步骤1-4 | 强制推理→自检→输出流程 |
| ⑥ 提供参考 | `<context><reference>` | 参考资料独立区块，要求依证据作答 |
| ⑦ 拆分复杂任务 | `<instructions>` 分步 | 理解→检索→推理→验证→输出五步拆解 |
| ⑧ 约束输出格式 | `<output_format>` | 结构化模板 + "不输出推理过程" |
| ⑨ 允许说"不知道" | `<safety>` + `<output_format>` 不确定项 | 显式兜底，禁止编造 |
| ⑩ 对话历史管理 | `<conversation_history>` | 仅留相关历史，压缩噪声 |
| ⑾ 防上下文干扰 | `<instructions>` 推理规则 | "无关信息忽略""矛盾指出不强行统一" |

## 使用示例：填充后的效果

```
<role>
你是一位 资深财务分析师，具备以下专业能力：
- 上市公司财报解读与同业对比
- 估值模型构建（DCF / 可比公司）
- 行业趋势研判
你的回答需体现该角色的专业判断力与严谨性。
</role>

<task>
分析宁德时代（300750）2024 年年报中的盈利能力变化，并指出主要驱动因素。
任务目标：输出一份结构化分析，含核心结论、数据依据、不确定项。
任务约束：中文，800 字以内，语气客观，不做投资建议。
</task>

<context>
以下是与本任务直接相关的参考信息，请基于这些信息作答，不得凭记忆编造未在此处出现的事实：

<reference>
宁德时代 2024 年年报数据：
- 营业收入 4009.17 亿元，同比 -9.7%
- 归母净利润 507.45 亿元，同比 +9.7%
- 毛利率 24.4%，上年 22.3%
- 研发费用 186.2 亿元，同比 -1.2%
- 期末存货 483.7 亿元，同比 -19.6%
</reference>
</context>

<instructions>
请按以下步骤完成任务：
1. 理解任务：分析盈利能力变化及驱动因素。
2. 信息检索：从参考资料中提取毛利率、净利率、费用率等关键指标。
3. 分析推理：净利润增速远高于营收增速，需解释原因（毛利率提升、费用控制、减值减少等）。
4. 验证自检：确认每个结论有数据支撑。
5. 组织输出。
</instructions>

<output_format>
## 结论
{{一句话核心结论}}

## 依据
- {{逐条列出数据依据}}

## 详细分析
{{分点展开}}

## 不确定项
{{无法确认的内容}}
</output_format>

<safety>
- 不确定时说"参考信息不足"，不得编造。
- 不臆测未给出的数据。
</safety>
```

## 设计哲学

```
清晰 > 精巧     —— 话要说清楚，花哨技巧是加分项
结构 > 长度     —— 用标签分区，胜过堆砌长文
证据 > 记忆     —— 用参考资料防幻觉
思考 > 直答     —— 推理在前，结论在后
```
